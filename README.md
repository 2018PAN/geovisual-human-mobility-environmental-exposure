# Human Mobility and Environmental Exposure Analysis

This repository contains the analysis code developed for my master's thesis, *Geovisual Exploration of Human Mobility and Environmental Exposure From a Geospatial Analysis Perspective*.

The scripts cover exposure decomposition, spatial autocorrelation analysis, Random Forest and XGBoost modelling, spatial cross-validation, and SHAP interpretation.

The input data are not included. The population activity data originate from a commercially operated mobile application and cannot be redistributed.

Main Python dependencies: pandas, NumPy, scikit-learn, XGBoost, SHAP, PySAL, pyproj, and joblib.
